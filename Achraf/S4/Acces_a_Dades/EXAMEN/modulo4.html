M4: BaseX XML y Spring Data JPA

Persistencia en XML nativo con XQuery/XQUF e integración mediante Spring Data JPA y Lombok

Progreso Global:

1 Bases de datos XML nativas (BaseX, XQJ y Escapado)

Las bases de datos documentales XML nativas almacenan documentos XML de forma jerárquica y permiten consultarlos mediante lenguajes específicos como XQuery. En este examen se evalúa el motor **BaseX** y la API de integración Java **XQJ**.

⚙️

Configuración del Servidor BaseX

Para conectar con BaseX mediante XQJ, se definen los parámetros del XQDataSource:
• El puerto por defecto es 1984.
• Las credenciales obligatorias por defecto son el usuario admin y la contraseña admin.

⚠️

Escapado de Comillas en XQuery

Trampa de examen: Al concatenar cadenas Java en consultas XQuery, si la variable contiene comillas simples o dobles, la consulta fallará.
• Si usas comillas dobles en el filtro XQuery, debes escaparlas en Java usando la barra invertida (ej: "[/canal[nom=\"" + nombre + "\"]]").
• Para evitar problemas, es recomendable usar comillas simples internas en XQuery (ej: "[/canal[nom='" + nombre + "']]") que no requieren escapado en las cadenas de Java.

Flujo de conexión y consulta con XQJ:

  • Obtener una conexión mediante un XQDataSource.
  • Crear un intérprete de expresiones con conn.createExpression().
  • Ejecutar consultas de lectura XQuery directas con executeQuery(consulta).
  • Recorrer el flujo de nodos devueltos (XQResultSequence) con seq.next() y extraerlos en formato texto con seq.getItemAsString(null).

2 Sentencias de actualización: XQUF

Para modificar el contenido de los documentos XML en BaseX se utiliza **XQUF (XQuery Update Facility)**. Las operaciones básicas de actualización son:

  • Inserción de nodos: insert node <nuevo_nodo/> into /ruta/padre.
  • Eliminación de nodos: delete node /ruta/nodo[@id='valor'].

3 Spring Data JPA y Registro de Beans

Spring Data JPA reduce el código repetitivo de persistencia. Únicamente se definen interfaces que extiendan de JpaRepository<Entidad, TipoClave>.

🚨

Inyección con @Autowired y Componentes de Spring

Error grave de examen: Si intentas inyectar una clase personalizada (como un DAO manual o un gestor intermedio) utilizando la anotación @Autowired, la clase de destino debe estar registrada como un Bean en el contenedor IoC de Spring.
Si la clase de destino carece de anotaciones como @Component, @Repository, o @Service, Spring no sabrá cómo gestionarla y lanzará un error de compilación o arranque indicando que el tipo de datos no es adecuado para la inyección automática.

Métodos heredados de JpaRepository evaluados:

save(), findById(), findAll(), deleteById(), existsById(), count(), etc.

Consultas personalizadas en Spring Data:

  • Métodos derivados (Query methods): Se autogeneran a partir del nombre del método (ej. List<Pista> findByColorAndOberta(String color, boolean oberta)).
  • Anotación @Query: Permite escribir consultas JPQL a medida en la interfaz. Se acompaña de @Param("nombre") para enlazar las variables.
  • Anotaciones de modificación: Si la consulta con `@Query` realiza operaciones de tipo UPDATE o DELETE, se deben añadir obligatoriamente las anotaciones **@Modifying** y **@Transactional**.

4 Lombok y recursión en relaciones bidireccionales

Lombok genera automáticamente getters, setters, constructores, toString y equals/hashCode mediante anotaciones (ej. @Data, @NoArgsConstructor).

💥

Recursión Infinita con @Data

Si dos entidades tienen una relación bidireccional (ej: Estacio tiene una lista de Pista, y Pista apunta de vuelta a Estacio), el uso de `@Data` en ambas clases causará que los métodos autogenerados toString() o hashCode() se invoquen mutuamente de manera indefinida, arrojando un error **StackOverflowError**.
**Solución de examen:** Excluir explícitamente el campo de referencia en la clase hija utilizando las anotaciones **@ToString.Exclude** y **@EqualsAndHashCode.Exclude**.

BaseX XQJ y XQUF CRUD

Java 
// Borrar un nodo en BaseX XML
String xq = "delete node doc('pistes/pistes.xml')/pistes/pista[@id='" + id + "']";
XQExpression exp = conn.createExpression();
exp.executeQuery(xq); // Ejecuta la modificación física del XML

Repositorios Spring Data JPA con modificaciones

Java 
@Repository
public interface PistaRepository extends JpaRepository<Pista, String> {
    // Método derivado automático por nombre
    List<Pista> findByColor(String color);

    // Query de modificación personalizada
    @Transactional
    @Modifying
    @Query("UPDATE Pista p SET p.oberta = :estado WHERE p.id IN :ids")
    int actualitzaEstatPistes(@Param("ids") List<String> ids, @Param("estado") boolean estado);
}

Solución Lombok a la Relación Bidireccional

Java 
@Entity
@Data
@NoArgsConstructor
public class Pista {
    @Id
    private String id;

    @ManyToOne
    @ToString.Exclude            // Evita bucle infinito en toString()
    @EqualsAndHashCode.Exclude  // Evita bucle infinito en hashCode() y equals()
    private Estacio estacio;
}

¿Qué diferencia hay entre XQuery y XQUF?
Haz clic para girar

XQuery se utiliza exclusivamente para realizar búsquedas y consultas de lectura, de forma análoga a un SELECT relacional.

XQUF (XQuery Update Facility) es la extensión que permite insertar, modificar o borrar nodos del documento XML.

¿Cuál es la sintaxis de XQUF para insertar un nodo?
Haz clic para girar

insert node {codigo_xml} into {ruta_padre}

Ejemplo: insert node <pista id="1"/> into doc('pistes.xml')/pistes añade el subnodo como hijo del tag pistes.

¿Por qué se requieren @Modifying y @Transactional en queries personalizadas?
Haz clic para girar

Porque Spring Data necesita identificar que la operación no es de lectura, sino de alteración física de registros.

Sin @Transactional, la transacción no se abrirá y el servidor lanzará una excepción.

¿Cómo provoca Lombok un StackOverflowError?
Haz clic para girar

Si el padre apunta a los hijos y los hijos apuntan de vuelta al padre, `@Data` crea un toString() recursivo en cadena que desborda la pila de ejecución de Java.

¿Cómo se elimina un nodo XML usando XQUF?
Haz clic para girar

Utilizando la sentencia delete: delete node {ruta_nodo}.

Ejemplo: delete node doc('pistes.xml')/pistes/pista[@id='1'].

¿Qué pasa si olvidamos anotar un Servicio con @Service?
Haz clic para girar

Spring Boot no registrará la clase como un bean en su contexto IoC, por lo que fallará cualquier intento de inyección automática con @Autowired.

¿CrudRepository vs JpaRepository?
Haz clic para girar

CrudRepository provee funciones CRUD básicas. JpaRepository hereda de él y añade métodos específicos de JPA (paginación, ordenación y vaciado inmediato al disco).

¿Por qué inyección por constructor?
Haz clic para girar

Es la recomendada sobre @Autowired en campo. Facilita los tests unitarios y permite declarar las dependencias como final asegurando inmutabilidad.

1. ¿Cuál es el procedimiento correcto para extraer el XML en formato texto de una consulta en XQJ?
  • Leyéndolo de forma directa desde el objeto XQExpression.
  • Usando la serialización JAXB directamente contra el origen de datos.
  • Iterando con next() la secuencia XQResultSequence y llamando al método getItemAsString().
2. En Spring Data JPA, si definimos un método con la anotación @Query para ejecutar una sentencia UPDATE, ¿qué otras anotaciones son obligatorias?
  • Únicamente la anotación @Repository en la cabecera.
  • Las anotaciones @Modifying y @Transactional.
  • No se necesita ninguna anotación adicional si devuelve un entero.
3. ¿Cómo se resuelve el bucle de recursión infinita en Lombok al mapear una relación bidireccional en JPA?
  • Colocando @ToString.Exclude y @EqualsAndHashCode.Exclude en la propiedad de referencia de la clase hija (lado ManyToOne).
  • Eliminando la anotación @Entity en alguno de los dos extremos de la relación.
  • Reemplazando @Data por @Getter y @Setter en todas las clases.

  • Puerto 1984, usuario 'admin', contraseña 'admin'.
